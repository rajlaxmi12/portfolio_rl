# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/rajlaxmi12/portfolio_rl.git
```

## Navigate into the project

```bash
cd portfolio_rl
```

## Install dependencies

```bash
npm install
```

## Run locally

```bash
npm run dev
```

The application will start on:

```
http://localhost:5173
```
